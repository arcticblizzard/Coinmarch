# Enterprise Rolls

Enterprises represent the players’ ongoing pursuits—personal projects, group undertakings, and relationships that unfold over time. Each Enterprise is tracked on a six-step progress track, marking advancement toward completion or decline. When time passes, an Enterprise Roll determines how effort, circumstance, or neglect alters that progress. In Coinmarch, progress is never guaranteed; every endeavor must be tended, or it slowly slips away.

---

# Enterprise Roll Workflow

To complete an Enterprise Roll, the four following steps must be followed:

<div class="grid cards" markdown>

-   :material-tune: __Declare the Enterprise__

    ---

    - A Player or GM can call for an Enterprise roll during an appropriate activity, describing its focus (project, reputation, etc).
    - A Player then narrates how their character contributes to this Enterprise during this period.
    - The GM will then select the most relevant skill and request a Skill Check

-   :material-dice-d20:{ .lg .middle } __Player Skill Check__

    ---

    The Player then makes the associated Skill Check with the normal DC20.

-   :fontawesome-solid-list-check: __Set Circumstance__

    ---

    The result of the Skill Check will directly impact a value called **Circumstance**. This represents any extenuating circumstances leading up to the execution of the Enterprise.

    | Skill Roll Result | Circumstance Value |
    | ----------------- | ------------------ |
    | Critical Success  | +2                 |
    | Success           | +1                 |
    | Failure           | -1                 |
    | Critical Failure  | -2                 |

    An additional -1 penalty may be assessed to account for Decay (see section below).

-   :material-gavel: __Execute Enterprise__

    ---

    The Player will then roll a `1d6`, apply their Circumstance value and apply the result to the Enterprise in question.

    | Adjusted Roll | Effect   | Description                |
    | ------------- | ------   | -------------------------- |
    | <=0           | -2 steps | Major Setback              |
    | 1-2           | -1 step  | Minor regression           |
    | 3-4           | 0 steps  | Stalled progress           |
    | 5-6           | +1 step  | Incremental progress       |
    | >=7           | +2 steps | Breakthrough or major gain |

</div>

# Additional Rules and Notes

## Decay

Time and neglect wear on every pursuit. If an Enterprise is left unattended for a full downtime interval, it begins its next Enterprise Roll with **Circumstance –1** to reflect lost momentum, fading interest, or outside interference. This penalty does not stack, and it resets once an Enterprise Roll has been attempted for that Enterprise. In Coinmarch, even idle ambitions cost you ground.
